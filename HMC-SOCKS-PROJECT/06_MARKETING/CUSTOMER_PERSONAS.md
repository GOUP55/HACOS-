## 全体設計意図

初回商品は「朝のランニング→ジム→日常」を1足でつなぐ想定（PROJECT_BRIEF.md 4章）。
3タイプのうち**タイプC「シンプルな暮らしを好む人」は女性を中心に据え**、ここを起点に「運動が主目的でなくても選ばれる靴下」という位置づけを作る。
S（22.5〜24.5cm）を用意する設計（DECISIONS.md P2）は、女性の足のサイズを想定した意図的な選択であり、タイプA・Bにも女性が自然に含まれる前提で書く（「男性向け・女性向け」と分けない）。

## タイプA｜朝に走る人（RUNFREE常連層）

| 項目 | 内容 |
|---|---|
| 年齢帯 | 30〜50代（性別問わず。RUNFREE参加者の年齢層は運営側の肌感で、正式な集計値ではない） |
| 性別 | 男女混在。日曜朝の無料RUNは性別を問わず参加できる場 |
| 運動習慣 | 週1回以上のランニング習慣あり。RUNFREE（毎週日曜AM6:30・参加費¥0）常連、または朝活クラス（AM7:30〜）併用者 |
| 悩み（一般に観察できる範囲） | 普通の靴下だと走行中に指が擦れる／汗で靴の中で滑る感覚がある／五本指靴下は種類が少なく選択肢が限られる |
| 購入理由 | 普段からRUNFREEに参加しているブランドの靴下であること。5本指の履き心地を一度試したい／続けている習慣の一部として揃えたい |
| 使用場面 | 日曜朝のRUNFREE、平日早朝のランニング |
| 価格許容度 | ¥2,750（税込・仮）は「試しやすい価格」として受け止められやすい層。2足セット¥5,280（仮）はリピート・色違いで検討されうる |
| 既存の靴下への不満 | 五本指ソックスは指先の耐久（穴あき）が早い／締め付けが強く長時間だと窮屈／見た目がスポーツ専用感が強く日常では履きにくい |

| 項目 | 内容 |
|---|---|
| 年齢帯 | 20〜40代 |
| 性別 | 男女混在。HACOSのセミパーソナル・朝活クラス利用者を想定 |
| 運動習慣 | 週1〜3回のジムでの筋トレ・セミパーソナルトレーニング。ランニングは必須ではない |

| 購入理由 | 「ジムでも日常でも1足で済む」という実用性。HACOSのトレーナーやコミュニティで実際に履いている人を見て興味を持つ |
| 使用場面 | ジムでのトレーニング、そのまま買い物や通勤などの日常 |
| 価格許容度 | ¥2,750（税込・仮）は「消耗品としては高め、ブランド品としては手頃」という受け止めが想定される。2足セットで複数枚持ちを検討しやすい |
| 既存の靴下への不満 | スポーツ用靴下は日常で履くとデザインが浮く／逆に日常用の靴下はジムで滑りやすい・蒸れやすい |

## タイプC｜健康的でシンプルな暮らしを好む人（女性中心）

| 項目 | 内容 |
|---|---|
| 年齢帯 | 30〜50代 |
| 性別 | **女性中心**。運動が主目的ではなく、日々の暮らしの質を整えたい層 |
| 運動習慣 | 運動習慣は「あり／なし」どちらもあり得る。ウォーキングや軽いストレッチ程度、または運動習慣は特にないが健康的な生活に関心がある |
| 悩み（一般に観察できる範囲） | 靴下の指の間の蒸れが気になる／五本指靴下は見た目がゴツく普段使いしにくいものが多い／シンプルで長く使える定番品を探している |
| 購入理由 | 「HEALTHY MORNING CLUB」というブランドの世界観（丁寧な暮らし・朝の習慣）への共感。デザインがシンプルで日常に馴染むこと。GOのIG（@go_room91）やhmc.dayの投稿を見て知る |

| 価格許容度 | ¥2,750（税込・仮）は「日常使いの靴下」としてはやや高価格帯だが、ブランド・デザイン・素材への納得があれば許容されうる層。ギフト用途での2足セット購入も想定 |
| 既存の靴下への不満 | 五本指靴下は「機能重視・見た目は二の次」なものが多く選択肢が少ない／普通の靴下はすぐへたる・穴が空く |

## 設計上の含意（女性に自然に選ばれるための意図）

- サイズ展開にS（22.5〜24.5cm）を含める（DECISIONS.md P2）ことで、女性が「自分のサイズがある」と迷わず選べるようにする
- カラーはBLACK×WHITE 1色スタート（DECISIONS.md P3）とし、性別で色を分けない設計にする
- 訴求文言・ビジュアルは「男性向け／女性向け」と区分せず、タイプCのようにブランドの世界観・暮らしへの共感で選ばれる導線をSNS・LPで用意する（詳細はSNS_CONTENT_PLAN.md）
- いずれのタイプにも医学的・治療的効果（外反母趾改善・姿勢矯正等）は訴求しない（DECISIONS.md D7）
