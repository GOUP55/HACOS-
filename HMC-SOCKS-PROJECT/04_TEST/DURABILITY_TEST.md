# DURABILITY TEST — 耐久試験（実使用ベース）

> 作成: 2026-08-01。専用試験機は持たないため、**実使用ログ＋洗濯試験**で耐久を評価する。機械試験（摩耗・破裂・ピリング等）が必要になった場合は工場または外部検査機関に依頼する（費用はQUESTIONS.md工場確認項目に含める）。

## 実使用耐久ログ（GO＋ラン習慣テスター）

| 記録項目 | 内容 |
|---|---|
| 使用日・用途 | ラン（距離km）／ジム／日常 |
| 累積使用回数・累積ラン距離 | 1足ごとに記録（足に個体番号を振る: 例 M-01） |
| 異常の初出 | 薄くなり・毛玉・ほつれ・穴が「いつ・どこに」出たか＋写真 |

- 目標の目安（仮・達成基準ではなく観察基準）: 週3使用×3ヶ月で穴が開かないこと。実測して基準化する
- 最も摩耗した部位を特定し、2ndサンプル・量産での補強位置に反映する

## グリップ・フィットの経時変化

- 洗濯10回・20回時点で「新品と履き比べ」を行い、ズレにくさ・アーチのフィット感の低下を官能5段階で記録
- PU（ポリウレタン）のへたりは履き口で最初に出やすい。履き口の復元性を毎回チェック

## 外部機関試験（実施は任意・表現に使いたくなったら必須）

「耐摩耗性◯倍」「破裂強度」等の**数値訴求をする場合のみ**、公的検査機関での試験を実施する。試験なしの場合、販売ページには「つま先・かかと補強糸使用」「洗濯20回テスト実施」など**構造と実施事実のみ**を記載する（BUSINESS_RULES.md の実績表現ルールに従う）。
