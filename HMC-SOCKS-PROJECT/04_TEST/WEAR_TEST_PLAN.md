# WEAR TEST PLAN — 着用テスト計画

> 作成: 2026-08-01。サンプル到着後に実施。テスター募集はGO承認後（QUESTIONS.md Q5）。

## テスター構成

| 区分 | 人数 | 条件 |
|---|---|---|
| GO本人 | 1 | 全条件を実施（基準テスター） |
| RUNFREE・朝活参加者 | 4〜5 | 男女両方を含める（S/M両サイズを必ずカバー）。ラン習慣あり2名＋ジム中心2名＋立ち仕事や日常中心1名が理想 |

- テスターには無償提供＋結果アンケート（`TESTER_QUESTIONNAIRE.md`）を依頼。感想を販売ページで使う場合は**掲載許可を書面（LINEでの明示同意）で取得**し、「個人の感想です」表記を付ける
- サンプル数が足りない場合はGO＋2名（男女各1）に縮小し、洗濯テストを優先する

## テスト条件（発注書指定の7条件）

| 条件 | 内容 | 最低実施 |
|---|---|---|
| ウォーキング | 30分以上 | 全員 |
| ランニング | 5km以上（RUNFREEで実施可） | ラン習慣者 |
| 筋力トレーニング | ジムセッション1回 | ジム中心者 |
| 一日着用 | 起床〜夜まで（通勤・立ち仕事含む） | 全員 |
| 3回洗濯後 | 再度ウォーキングor日常着用 | 全員 |
| 10回洗濯後 | 同上＋外観評価 | GO＋1名 |
| 20回洗濯後 | 外観・寸法評価中心（`WASH_TEST.md`） | 管理者（洗濯は管理者側でまとめて実施） |

- 洗濯回数の管理: テスターに任せず、**回数管理用の1〜2足は管理者（GO側）が保有して規定条件で洗濯**する（条件は `WASH_TEST.md`）

## 評価項目（20項目・5段階）

`TESTER_QUESTIONNAIRE.md` を使用。集計は `TEST_RESULTS.csv`。

## 合否判定

- 20項目の平均 **4.0以上**、かつ「日常で履きたいか」**4.5以上**、かつ致命的指摘（痛み・破れ・大きなズレ）ゼロ → 量産仕様承認へ
- 未達の場合: 指摘上位3件を `SAMPLE_REQUEST.md` の2nd修正欄に記入して再サンプル
- 判定に迷う項目は「その項目が優先用途（朝RUN・ジム・日常）に致命的か」で決める（例: ヨガでの滑りは初回はスコープ外）

## スケジュールの目安

サンプル到着 → 週内にテスター配布 → 2週間で着用＋アンケート回収 → 洗濯20回評価は並行で約3週間 → 判定会（GO＋チーム）
