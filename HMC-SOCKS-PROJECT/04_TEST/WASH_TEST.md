# WASH TEST — 洗濯試験手順

> 作成: 2026-08-01。管理者（GO側）保有のサンプルで実施する規定条件テスト。テスター各自の洗濯とは別に、条件を揃えて劣化を記録する。

## 洗濯条件（家庭での実使用に合わせる）

- 洗濯機: 家庭用縦型またはドラム式（使用機を記録: ____________）
- 条件: 標準コース／水温常温／中性洗剤（柔軟剤なし）／洗濯ネット**なし**（厳しめ条件で見る）
- 乾燥: 陰干し（乾燥機は使わない。乾燥機の影響は別途1足で確認）
- ※工場推奨の洗濯条件を聞いた場合は、その条件でのテストも並行し、`CARE_INSTRUCTIONS.md` の根拠にする

## 測定タイミングと項目

3回・10回・20回洗濯後に以下を記録（`TEST_RESULTS.csv` の wash_count 列）:

| 項目 | 方法 |
|---|---|
| 総丈・足底長（平置き） | `SIZE_SPEC.md` の採寸ポイントでメジャー実測。洗濯前の初期値との変化率を出す |
| 毛玉 | 目視5段階（5=なし〜1=広範囲）＋写真記録 |
| パイルのへたり | 前足部を指で押した官能5段階＋写真 |
| 履き口ゴムの伸び | 平置き幅の実測＋復元の官能評価 |
| 刺繍・ジャカードの状態 | ほつれ・欠け・毛羽の目視＋写真 |
| 色（退色・色移り） | 洗濯前の未使用品と並べて目視比較＋写真 |
| 穴・薄くなり | つま先・かかと・母趾球部を透かして確認 |

## 記録のルール

- すべて**同一条件・同一光源で写真を撮る**（比較可能にする。スマホ固定でOK）
- 数値は `TEST_RESULTS.csv`、写真は `04_TEST/photos/`（洗濯回数_部位.jpg）に保存
- 合格ライン: `03_MANUFACTURING/QUALITY_STANDARDS.md`（洗濯5回後−7%以内は目標値。実測でラインを現実化する）

## 判断への接続

- 20回後に穴・大きな型崩れ → 補強・糸構成の変更を2ndサンプルで要求
- 縮み率が大きい → サイズ設計に縮み代を織り込む（工場と相談）
- 問題なし → 「洗濯20回テスト済み」という**事実の記述**として販売ページに書ける（効果の誇張はしない）
