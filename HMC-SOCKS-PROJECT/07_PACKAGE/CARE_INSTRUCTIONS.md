# CARE INSTRUCTIONS — お手入れ表示・案内文

> 作成: 2026-08-01。最終的な洗濯表示（記号）は**工場の指定に従う**。以下は案内文のドラフトと決定手順。

## お手入れ案内文（下げ札・商品ページ用ドラフト）

```
【長く履いていただくために】
・洗濯ネットのご使用と裏返し洗いをおすすめします
・乾燥機のご使用は縮み・傷みの原因になります。陰干しをおすすめします
・漂白剤・柔軟剤はお避けください（柔軟剤は吸水性を下げることがあります）
・パイル（クッション部）の糸が飛び出した場合は、引っ張らずにハサミでカットしてください
```

※「おすすめします」表現で統一（断定・強制はしない）。実際の禁止事項（乾燥機不可等）は工場指定の洗濯記号が正。

## 洗濯表示（法定表示）の決定手順

1. 工場に、量産仕様での推奨洗濯記号（現行JISの洗濯表示）を確認
2. `04_TEST/WASH_TEST.md` の実測（ネットなし厳しめ条件）と矛盾しないか確認
3. 確定した記号を `PRODUCT_LABEL.md` に記載し、帯裏面・下げ札の入稿データに反映

## よくある質問への回答方針（商品ページFAQと整合）

- 「乾燥機は使えますか」→ 工場指定に従い、推奨しない場合はその旨を正直に
- 「毛玉になりますか」→ 素材の性質として起こり得ることを隠さず、テスト実測（10回・20回洗濯）の事実を書ける範囲で書く
