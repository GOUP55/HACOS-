# PACKAGE CONCEPT — パッケージ設計

> 作成: 2026-08-01。方針: ブランドの顔になる最小限のパッケージ。過剰包装しない（コストと思想の両面）。

## 構成（1足あたり仮 ¥100・ASSUMPTIONS A6）

| 要素 | 仕様案 | 役割 |
|---|---|---|
| 紙帯（メインパッケージ） | 未晒しクラフトまたはCREAM系の厚紙帯。表: MCモノグラム（黒）＋商品名。裏: サイズ・混率・洗濯表示・表示者 | 店頭・イベント手売りでも成立する顔 |
| 下げ札 | 小型タグ1枚。タグライン「この人生を、走り抜けれるように」＋ブランドストーリー短文（BRAND_NARRATIVE 100字版） | 世界観の伝達 |
| QRコード | 下げ札裏に公式LINE（https://lin.ee/TsRy6I9）への導線。「HEALTHY MORNING CLUBの朝はここから」 | 購入者をコミュニティへ |
| OPP袋 | 配送時のみ使用（イベント手売りは帯のみ） | 汚れ防止・簡素に |
| 配送外装 | 厚紙封筒（ポスト投函便対応サイズ） | 送料を抑える（A7） |

## デザイン原則

- 色数を絞る: 紙地色＋黒（＋DEEP GREEN `#0E3218` を1点まで）
- 正式名称は必ず「HEALTHY MORNING CLUB」（Health Morning Club 表記の流用禁止・D2）
- タグラインは「この人生を、走り抜けれるように」の表記そのまま（D3）
- 効果表現は書かない。書くのは構造の事実（5本指・部位別クッション・補強）のみ
- 環境配慮素材（FSC紙等）は**コスト見積を取ってから**判断（思想には合うが初回コスト優先度は中）

## イベント限定セット（PRICING_MODEL: ¥5,000現金・2足）

- 通常帯2つ＋限定ステッカー（MCモノグラム）＋手渡し用クラフト袋
- 「RUNFREEの朝に手売りできる」ことを最優先（かさばらない・雨に強い）
