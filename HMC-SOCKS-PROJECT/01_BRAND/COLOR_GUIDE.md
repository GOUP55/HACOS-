# COLOR GUIDE — 配色ガイド

> 作成: 2026-08-01。HMC既存ブランドの配色と、ソックスのカラー展開を接続する。

## ブランド基準色（既存LP・CLAUDE.mdより）

| 名称 | 値 | 用途 |
|---|---|---|
| CREAM | `#F5F0E8` | 背景・ベース |
| FOREST | `#3D5A3E` | ブランドグリーン |
| AMBER | `#C8833A` | アクセント（MORNING GOLDの基準候補） |
| RUST | `#B85C38` | アクセント |
| DARK | `#1C1C1A` | テキスト・黒 |
| （参考）HMCロゴ深緑 | `#0E3218` | 2026-08-01にイメージ素材から実測。DEEP GREENの糸色指定の参考値 |
| （参考）支給ロックアップ実測 | Spees `#34535C`／筆文字 `#132E28`／モノグラム 黒 `#000000` | 2026-08-01支給画像（`01_BRAND/assets/`）より実測 |

- ロゴは**黒1色で成立**が原則（D5）。製品上は糸色1色で表現（白・黒・深緑・金茶）
- Webやパッケージでモノグラムを使う時は DARK `#1C1C1A`。カラー背景時は白抜き

## ソックスのカラーネーム（商品表記用）

| 商品カラー名 | ベース | ロゴ糸色 | 目標色の目安 |
|---|---|---|---|
| BLACK | 黒 | 白 | ベース: DARK寄りの黒（糸見本で決定） |
| CREAM | 生成り | 深緑 | ベース: CREAM `#F5F0E8` に近い生成り糸 |
| DEEP GREEN | 深緑 | 金茶（MORNING GOLD） | ベース: `#0E3218`〜FOREST `#3D5A3E` の間で糸見本から選定 |

- 実際の色は**工場の糸見本帳から選ぶ**（別注染色はロットが跳ね上がるため初回は既製糸色から選定。質問リスト済み）
- 選定した糸番号をこのファイルに追記して正とする

## 初回生産の推奨（承認待ちP3）

- **BLACK（白ロゴ）1色**: 在庫リスク最小・男女両用・ラン/ジム/日常すべてで使える
- DEEP GREEN × MORNING GOLD は「HMCらしさ」最強だが需要が読めないため、**先行予約限定・受注数のみ生産**が可能か工場に確認してから判断
- WHITE系はラン用途で足裏汚れが目立つため初回見送り（スタジオ向けGRIP型で再検討）

## 撮影・見せ方のメモ（ファッションディレクター視点）

- 商品写真はCREAM背景（LPと同一世界観）＋朝の自然光。黒ソックスが沈まないよう明るめに
- コーデ想定: ランシューズ／白スニーカー／ジム素足系トレーニングの3パターンを撮る
- 足元だけでなく「朝の支度」の文脈（玄関・朝日）で1カット
