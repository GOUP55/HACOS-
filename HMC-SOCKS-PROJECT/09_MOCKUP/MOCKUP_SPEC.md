## ロゴ配置（D10）

- **正面（すね〜カーフ）に縦型MCモノグラム**。支給リファレンス `01_BRAND/assets/mc-monogram-reference.png` の骨格（太ストローク・丸端・M上/C下）を踏襲
- ワードマーク「HEALTHY MORNING CLUB」は履き口下に小さく配置（※支給画像の「Health Morning Club」表記は誤りのため本データでは必ず正表記にする）
- 土踏まずのジャカードワードマーク候補は継続（テックビュー参照）

## 着用時の伸びへの対応（重要）

編地は着用時に**主に横方向（周方向）へ伸びる**。平置きで正円のロゴは、履くと横に太って見える。
- モックアップは着用時の見え方を表現。**製造データは横方向を約12%圧縮**（縦はそのまま）して作成する
- 圧縮率12%は仮の設計値。**1stサンプルで実測**（平置きと着用時のロゴ幅を測って補正）し、この欄を更新する
- 実現方法の推奨: カーフ正面の大型ロゴは**ジャカード編み込みを第一候補**（大面積の刺繍は硬さ・突っ張りが出て「素足感」と矛盾するため）。工場のジャカード再現性が低い場合は、サイズを落として刺繍にするか、圧着以外の方法を工場と協議
- 位置の目安: モノグラム上端＝履き口下端から約60〜70mm（着用時にふくらはぎの正面中央に来る位置。サンプルで調整）

## 機能ゾーン（テックビュー注釈と対応・トレラン/HYROX観点）

| ゾーン | 仕様 | トレラン/HYROXでの意味 |
|---|---|---|
| ハイソックス丈 | 膝下2〜3cm目標（サンプルで確定） | カーフを覆って保護（トレイルの擦れ・草木・砂利、バーピー等での脛の接触） |
| カーフサポート編み | ふくらはぎ部のサポート編み（着圧訴求はしない） | 走行中のたるみ・ズレ落ち防止 |
| ソフトリブ履き口 | 締め付けすぎない・跡が残りにくい | 長時間レースでの快適性 |
| 前足部・かかとハーフパイル | クッション＋補強 | 下り坂・ジャンプ/立ち込み動作の衝撃対応 |
| Y字ヒール＋補強 | 立体編み | シューズ内のズレ防止 |
| アーチサポート＋薄手メッシュ | フィット・通気・地面感覚 | 長時間でも蒸れにくい |
| 5本指＋つま先補強 | 左右専用・指股フラット | 指の踏ん張り・マメ対策の基本構造 |

※「保護」「クッション」は物理的な覆い・構造の説明として使用。怪我予防・疲労軽減などの効果断定はしない（D7）。

## 表現の注意（SNS・商品ページでモックアップを使う場合）

- 「開発中のモックアップ」であることを明記（完成品と誤認させない）
- HYROXは大会名のため、公式関連商品と誤認される表現をしない（「HYROXのような競技にも」等の一般的表現に留め、ロゴ使用はしない）
