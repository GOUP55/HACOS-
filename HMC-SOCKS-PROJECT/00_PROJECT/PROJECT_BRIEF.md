## 1. この商品の価値（1文）

**朝のランニングから一日の終わりまで、素足の自由さと壊れない安心感で「自分の足でもう一度進む」を支える靴下。**

## 2. 商品コンセプト（約100字）

素足で動いているような自由さ。一日中履ける快適さ。何度洗っても、何度走っても崩れない強さ。
HEALTHY MORNING CLUB が朝の一歩のためにつくった、5本指パフォーマンスソックス。

## 3. 商品の3本柱（オーナー決定・変更しない）

| 柱 | 意味 |
|---|---|
| FREEDOM | 指が独立して動き、足裏で地面を感じやすい。締め付けを減らし、自然な足の動きを邪魔しない |
| COMFORT | 汗・蒸れ・擦れ・ズレを抑え、朝の運動から日常まで快適 |
| TOUGHNESS | 破れにくく形が崩れにくい。**硬さではなく**、耐久・安心・グリップ・タフな使用への対応 |

## 4. 優先する使用シーン（全部を1商品で狙わない）

**初回商品（CORE 5 TOE HIGH）の優先順位:**
1. 朝のランニング（RUNFREE。ブランドの原点シーン）
2. トレイルランニング／HYROX系フィットネスレース（D11。ハイソックスでカーフを保護）
3. ジムでのトレーニング（セミパーソナル・筋トレ）
4. 日常生活・スニーカーとの併用

**初回では狙わないシーン（第2弾 GRIP 5 TOE の領域）:**
- ヨガ・ピラティス・裸足スタジオ（足裏グリップが主機能になるため別設計）
- 超軽量レーシング専用（競合が強く、初回の武器にしない）
