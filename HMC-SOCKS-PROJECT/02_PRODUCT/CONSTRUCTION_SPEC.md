# CONSTRUCTION SPEC — 編み・縫製仕様（CORE 5 TOE）

> 作成: 2026-08-01。編機・針数・糸番手は工場設備に依存するため、本書は「実現したい構造」を部位別に指定し、実現手段は工場と協議する（協議項目は末尾）。

## 部位別仕様

| 部位 | 仕様 | 目的 |
|---|---|---|
| 履き口 | ソフトリブ（幅広め・締め付け弱め）＋PUでホールド。ゴム跡が残りにくいバランス。**丈はハイソックス（膝下2〜3cm目標・D9）**。ワードマークは履き口下に小さく | COMFORT（M7） |
| カーフ（ふくらはぎ） | カーフサポート編み（ずり落ち防止・覆いによる保護）。**正面に縦型MCモノグラム＝ジャカード第一候補**（伸び補正12%仮・`09_MOCKUP/MOCKUP_SPEC.md`） | M11/M12（D9-D11） |

| 土踏まず | 薄手メッシュ＋サポート編み（アーチフィット）。ジャカードでワードマークを入れる候補位置 | フィット（M6）・地面感覚 |
| 前足部足裏 | ハーフパイル（クッション） | 接地の快適・耐久（M3） |

| 全体 | 吸汗速乾糸構成（`MATERIAL_COMPARISON.md` A案） | COMFORT（M10） |

## 編み・縫製の論点（工場と協議して決める）

1. **編機**: 5本指対応編機の種類・針数（細かめのゲージを希望。対応可能な範囲を確認）
2. **つま先の縫い目**: 5本指編成後のつなぎ処理方法（ゴロつきが残る処理なら、指先違和感テストを1stサンプルの最重要評価にする）
3. **指股の擦れ**: 指股部の編み目処理。擦れやすい場合の対策（糸の選定・編成調整）
4. **パイルの高さ**: 前足部・かかとのパイル高（「厚すぎてシューズがきつくなる」を避ける。ハーフパイル指定）
5. **アーチサポートの強さ**: 締め付けすぎると「アーチが痛い」評価になるため中程度から開始し、サンプルで調整
6. **ジャカード再現性**: 土踏まず部の小型ワードマーク「HEALTHY MORNING CLUB」または「HMC」の最小可読サイズ（無理なら刺繍・転写に変更 or 省略）
7. **洗濯耐久**: パイル抜け・PU劣化の想定耐久（家庭洗濯の推奨条件も工場に確認→ `07_PACKAGE/CARE_INSTRUCTIONS.md` に反映）

## 禁止・回避事項

- 足裏への刺繍（ゴロつき・摩耗のため不可）
- 過度な着圧設計（着圧を機能として謳わない方針のため）
- 装飾のための縫い付けパーツ（洗濯耐久・肌当たりを損なうもの）
