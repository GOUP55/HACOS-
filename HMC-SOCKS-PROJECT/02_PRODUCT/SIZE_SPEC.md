# SIZE SPEC — サイズ仕様

> 作成: 2026-08-01。寸法の最終値はサンプル採寸で確定する（ここでの数値は設計目標）。

## サイズ展開（承認待ちP2）

| サイズ | 対応足長 | 主な想定 | 備考 |
|---|---|---|---|
| S | 22.5〜24.5cm | 女性中心 | 女性会員が自然に選べるサイズを初回から必ず用意する |
| M | 25.0〜27.0cm | 男性中心 | GO本人のサイズ帯（要確認）を含む想定 |
| L | 27.5〜29.0cm | 大きめ | **初回は作らない**。先行予約でL希望が一定数（目安10足）出たら第1ロットに追加 |

- 左右専用設計（親指位置の最適化）。左右はロゴ位置または内側の表記で判別できるようにする
- 男女兼用・色も共通。「メンズ用/レディース用」という分け方はしない（サイズで選ぶ設計）

## 採寸ポイント（サンプル評価・量産検品で共通に使う）

| 測定点 | 定義 | 目標値の決め方 |
|---|---|---|
| 総丈 | かかと底〜履き口上端 | ハイソックス: 膝下2〜3cm（D9）。ずり落ちない丈とカーフ周りの適合をサンプルで決定 |
| カーフ周り | ふくらはぎ最大周囲部の平置き幅 | S/Mそれぞれで着用テスト（ふくらはぎが太めの人・細めの人両方で確認） |
| 足底長 | かかと〜親指袋先端（平置き） | 各サイズ対応足長の下限−2〜3cm（編地の伸びで対応。工場推奨に従う） |
| 足幅（平置き） | 前足部最広部 | 工場の型・ゲージ準拠 |
| 履き口幅・リブ長 | 平置き幅とリブの長さ | 「跡が残りにくい」目標。サンプルで締め付け官能評価 |
| 指袋長 | 親指・中指・小指の各袋 | 日本人足型基準の工場推奨に従い、指余り/突っ張りをテストで確認 |

## グレーディング方針

- S/Mの2サイズで足長22.5〜27.0をカバーするため、編地の伸縮設計が重要（サイズ間の中間の人がどちらでも履けるより、**各サイズの中心足長で最適**になるよう設計）
- 指袋はサイズごとにグレーディング（Sの指袋をMの縮小版にしない。女性の足型で指袋が長すぎると指余りが出るため、サンプルはS/M両方を必ず作る）

## サンプルで確認すること

- S: 22.5cmの人と24.5cmの人の両端で指余り・突っ張りがないか（テスターは 04_TEST/ で確保）
- M: 25.0cmと27.0cmの両端で同上
- 洗濯後の縮みを見込んだ寸法設定（洗濯試験 `04_TEST/WASH_TEST.md` の実測で調整）
