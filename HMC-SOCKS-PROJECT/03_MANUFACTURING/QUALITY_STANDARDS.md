# QUALITY STANDARDS — 量産合格基準

> 作成: 2026-08-01。数値はチームの初期案。**サンプル実測と工場の標準公差を聞いた上で最終確定**する（無理な公差を要求すると単価が上がるため、工場標準との擦り合わせが前提）。

## 寸法（平置き・洗濯前）

| 項目 | 基準 |
|---|---|
| 総丈・足底長 | 仕様値 ±5%以内（工場標準公差と比較して調整） |
| 左右ペア差 | 同一ペア内の総丈差 5mm以内 |
| 洗濯後寸法変化 | 家庭洗濯5回後 −7%以内（目標。サンプル実測で現実的な値に更新） |

## 外観・仕上げ

| 項目 | 基準 |
|---|---|
| 編み傷・穴・伝線 | ゼロ（発見時は不良） |
| 糸の飛び出し | 表面に5mm以上の浮き糸なし。裏の渡り糸は指入れを妨げない |
| 刺繍 | 位置ズレ 左右比較で3mm以内／ほつれ・欠けなし／裏当ての肌当たり許容（官能） |
| ジャカード | 文字判読可能（不可の場合はその仕様を廃止） |
| 汚れ・油じみ | なし |
| 色 | 承認サンプル（量産前の色承認見本）との目視同等。ロット間の著しい色差なし |

## 機能（量産ロットの抜き取りで確認）

| 項目 | 基準 |
|---|---|
| 指入れ | 全指スムーズ（引っかかりなし） |
| 履き口ゴム | 伸ばして戻したとき復元する（PU切れなし） |
| 毛玉（ピリング） | 家庭洗濯10回後、目立つ毛玉が広範囲に発生しない（テスト実測を基準化） |

## 表示・付属

- 混率表示・洗濯表示・表示者名が `07_PACKAGE/PRODUCT_LABEL.md` と一致していること
- サイズ・L/R表記の取り違えなし
- 検針済み（縫い針・折れ針の混入対策。工場の検針体制を事前確認）

## 抜き取り検品の運用

- 受入時: ロットの10%を `INSPECTION_CHECKLIST.md` で検品。重欠点（穴・汚れ・表示違い）が1つでも出たら全数検品に切り替え
- 不良の扱い: 重欠点=販売不可／軽欠点（僅かな編みムラ等）=イベント試着用・テスター用に回す
- 不良率の記録を取り、工場へのフィードバックと次ロットの基準改定に使う
