# 運営インプット（数字とスタッフ報告を貼る場所）

> **これは「Claudeに渡す数字の唯一の入口」です。** 予約データは本番（Cloudflare D1）にあり、
> Claudeからは読めません。ここに転記された実数だけを `hacos-analyst` / `hacos-operator` が使います。
> **空欄は空欄のままでOK。**「未取得」として扱われます。埋めるために推測を書かないでください。
>
> 使い方: 数字を貼る → `/ops`（週次まとめ）または `/numbers`（数字レポート）と打つ。

---

## 数字の取り方（どこを見るか）

| 項目 | 取得場所 |
|---|---|
| 朝活の予約数・参加人数・キャンセル | LINE予約システムの管理画面（`/admin-login` からログイン → 予約一覧） |
| 体験パーソナルのリクエスト数・確定数 | 同 管理画面（体験リクエスト欄） |
| お弁当・TACOSの個数 | 同 管理画面の集計行（🍱×N） |
| LINE友だち追加数・ブロック数 | LINE Official Account Manager → 分析 → 友だち |
| LP閲覧数・CTAクリック・ガイド読了 | GA4（G-4CK1EXGHYV） |
| 売上（現金・Stripe） | 現金＝スタッフ報告／オンライン＝Stripeダッシュボード |
