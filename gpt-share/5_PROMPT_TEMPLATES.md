# GPTへの依頼テンプレ（コピーして使う）

> 使い方: 【】の中だけ書き換えて貼る。
> どのテンプレも**最後にGOが確認してから出す**前提。GPTの出力をそのまま配信しない。

## A. 考えを整理したいとき

### A-1. 頭が散らかっている
```
いま頭の中にあることを、順番も整理せずに全部書き出します。
そちらで、①事実 ②不安 ③やりたいこと ④決めなければいけないこと の4つに仕分けてください。
そのうえで「今週やること」を3つだけ選んでください。理由も添えてください。

【思っていることを全部書く】
```

### A-2. 迷って決められない
```
【迷っていること】で迷っています。
選択肢を3つに整理し、それぞれの「得られるもの」「失うもの」「後戻りできるか」を表にしてください。
そのうえで、私の価値観（無理に拡大しない／借金を増やさない／自分が不在でも回る／
人の心身が最優先）に照らして、いちばん私らしい案を1つ選んでください。
最後に「この決断で何を捨てることになるか」も書いてください。
```

### A-3. しんどいとき
```
いま少ししんどいです。励ましはいりません。
まず、私が何に疲れているのかを言葉にする手伝いをしてください。
そのうえで、いま手放していいものを1つだけ提案してください。
```

## B. 企画・数字

### B-1. 新しい企画を考える
```
【企画のざっくりした思いつき】を考えています。
提案の順番（①状況整理 ②私が本当に求めているものの仮説 ③選択肢3案 ④長所短所
⑤最も私らしい案 ⑥次の行動3つ）で出してください。

条件:
- 初期費用はできるだけかけない（借金を増やさない）
- 私が不在でも回る形にできるか必ず検討する
- 数字を出すときは「仮定」と明記し、根拠になる前提も書く
```

### B-2. 収支を試算する
```
【商品名】の収支を試算してください。
決まっている数字: 【価格・謝礼・原価など】
決まっていない数字: 【未確定のもの】

未確定のものは、幅（下振れ・中央・上振れ）で置いて、必ず「これは仮定です」と明記してください。
最後に「この試算がひっくり返るとしたら、どの数字が動いたときか」を1つ挙げてください。
```

### B-3. 月のクラス・メニューを組む
```
【◯月】の日曜クラス【回数】回ぶんを設計してください。

前提:
- お客様は50代女性中心。運動を続けられなかった経験がある方が多い
- 1回45分。AM7:30〜。会場は観音寺のHACOS
- 月の中で身体を一周させる組み方にしたい（例: 9月は 肩と背中→おしりと脚→お腹まわり→お腹の奥）
- 【担当できるトレーナー】

出すもの: 月のテーマ1つ／各回のクラス名（お客様がイメージできる言葉で）／
各回のねらい1行／トレーナー共有用の一言／お客様向けの告知文
```

## C. 文章

### C-1. LINE配信の文面
```
公式LINEで配信する文面を作ってください。

伝えたいこと: 【内容】
お客様: 50代女性中心。「しんどい」「めんどくさい」「どうせ続かない」が口癖の方
長さ: 【300字程度】

守ること:
- 効果を断定しない。「必ず」「絶対」「リバウンドしない」は使わない
- 残りわずか等、確認できない在庫表現を使わない
- 不安を煽らない。押し売りしない
- 押しつけずに、一緒にやりましょうという温度で

3案ください。それぞれ「どんな人に刺さるか」を一行添えてください。
```

### C-2. Instagramのリール台本
```
Instagramのリール台本を作ってください。

テーマ: 【 】
ペルソナ: 50歳女性・子ども3人・自営業の妻。体力低下と体型崩れ、ダイエットの失敗を繰り返している。
障壁は「自分にお金をかける罪悪感」「周囲の目」「どうせ続かない」。
ゴール: 公式LINEへの登録／保存

構成: 冒頭3秒のフック → 共感（コールドリーディング）→ 解決策 → CTA。30秒。
薬機法・景表法を守る（「治る」「痩身効果」「誰でも必ず」は使わない。「!?」「私の場合は」で緩和する）。
キャプションも付けてください。
```

### C-3. 書いた文章を人間らしくする
```
以下の文章、AIっぽさが残っています。人が書いた文章に直してください。
意味は変えず、いい人ぶった言い回しと、整いすぎた対句を減らしてください。

【文章】
```

## D. 確認・検算

### D-1. 出してよい文面かチェックする
```
以下の文面を、公開前チェックしてください。実装や書き直しはせず、指摘だけ出してください。

見る観点:
1. 効果の断定・誇大表現（薬機法・景表法）
2. 実績数値の根拠と「効果には個人差があります」の有無
3. 価格・日付・定員が、渡した資料と一致しているか
4. 確認できない在庫表現（残りわずか等）
5. 資格・肩書の表記ルール違反
6. 関係者の体験談にスタッフである旨の明記があるか

重大度（高・中・低）をつけて一覧にしてください。

【文面】
```

### D-2. 前提を疑ってもらう
```
【計画や決定】を進めようとしています。
実行する前に、私が気づいていない前提や、決めていない分岐を3つ挙げてください。
そのうち、答えによって設計そのものが変わるものを1つだけ選んで質問してください。
```

## E. GPTで決まったことをClaudeに戻す

GPTで結論が出たら、**そのまま忘れると存在しなかったことになる。**
次の形でClaude Codeに貼ると、正本に記録される。

```
GPTと壁打ちして、次のことが決まりました。BUSINESS_RULES.md に記録して、
関係するファイル（LP・特商法・予約システム）に反映が要るか調べてください。
実装はまだしないで、影響範囲だけ先に出してください。

決まったこと:
- 【 】
- 【 】

決めた日: 2026-__-__
```

## GPTがうまく答えないときの直し方

| 症状 | 直し方 |
|---|---|
| 古い価格を出してくる | 「プロジェクトのファイルを見て。記憶で答えないで」と伝える。ファイルが古いなら差し替える |
| 一般論しか返ってこない | 「うちの前提（50代女性・観音寺・チーム制）に当てはめて書き直して」 |
| 提案が薄く広い | 「案は3つまで。それ以外は捨ててください。捨てた理由も書いて」 |
| 長すぎて読めない | 「結論を先に。全体を800字以内で」 |
| 決めつけてくる | 「断定しないで。確証がないところは『確証がない』と書いて」 |
| 質問攻めにされる | 「質問は1つまで。まずあなたの解釈で答えてから聞いて」 |
