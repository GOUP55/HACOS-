# 世界観と、書いてはいけない表現

> ここに書いてある禁止表現は、好みの問題ではなく**法律と信用に直結**する。
> 薬機法（効果の断定）／景品表示法（誇大・二重価格）／ステルスマーケティング規制。

## 1. 世界観

**「身体が整う」「半径5mの幸せ」。でも、日常に取り入れやすい。**

- 発酵・スパイス・和の要素
- 単なるカフェではなく、「トレーニング後に食べたくなる食事」「家に持ち帰って生活が整う食事」
- 押し売りしない。温かく、誠実に

キーコピー … 「動く × 食べる × つながる」／「ひとりじゃない」／「全ては、朝から始まります」

## 2. トーン

| こう書く | こう書かない |
|---|---|
| 一緒にやりましょう | 頑張ってください |
| 出られる週だけで大丈夫です | 毎週必ず来てください |
| 合わなければ、そこでやめて大丈夫です | 絶対に結果が出ます |
| ◯◯さんの場合は | 誰でも／必ず |
| まだ決まっていません。決まり次第お知らせします | （決まっているかのように書く） |

**迷いやリスクを感じる文面ほど、短く書く。盛らないことが信頼になる。**
不安を煽って売らない。共感は、お客様が実際に語った事実の範囲で書く。悩みを盛って煽らない。

## 3. 配色とフォント（LP・バナー共通）

| トークン | 色 | 使いどころ |
|---|---|---|
| cream | `#F5F0E8` | 背景 |
| forest | `#3D5A3E` | 主色 |
| amber | `#C8833A` | **CTAの主役はこれ1つ** |
| rust | `#B85C38` | アクセント |
| dark | `#1C1C1A` | 文字 |

フォントは **Cormorant Garamond / Noto Serif JP / DM Sans の3つだけ。**

- ポップな装飾（`＼ ◯◯❣ ／` のような囲み）は押し売り感が出るので使わない
- LINE緑のボタンを複数並べない（ブランドカラーが負ける）
- モバイルファースト。基準幅は390px

## 4. 使ってはいけない表現

### 効果の断定・約束
- 「リバウンドしない」「必ず痩せる」「◯kg減が保証されます」
- 「科学的に実証された食事療法」（出典のない権威付け＋医療用語）
- 「10年後は今よりずっと健康に」（未来の効果の約束）
- 「治る」「美白」「痩身効果」
  → 言い換えは「スッキリ」「整う」「軽くなる」「私の場合は」「〜という声をいただきました」

### 実績まわり
- 提供された素材にない**ビフォーアフター数値を作らない**
- 実績に触れるときは必ず **「効果には個人差があります」** と掲載許可の確認を添える
- 「残りわずか」「お席はまだございます」など、**検証できない在庫表現を使わない**（事実の数で書く）

### 資格・肩書
- みどり … **「フードスペシャリスト」**。「管理栄養士」「栄養士」は**全媒体で使用禁止**
- ちひろ … **「Trainer / Pilates」**。「Yoga」は付けない
- 瞑想会の講師 … **「宗林寺・岡田隆弘僧正」で統一**。「現役僧侶」は使わない
- 理学療法士・整体師との提携 … **「準備中」**。「連携済み」「提携済み」と書かない
- 食事監修 … 「HACOS KITCHEN監修」「フードスペシャリスト監修」で統一

### 価格の見せ方
- **架空の「セット価格」との比較は二重価格表示になる。**
  ジャーニーの単品換算¥104,000が使えるのは、内訳の3商品が**実際にその価格で単品購入できるから**
- 単品価格を変えたら、比較額も必ず直す
- 「¥88,000」（古い計算）は使わない
- 都度払いの支払い方法は **「現金」** と書く（PayPay等は書かない）

### 関係性の明示
- **スタッフや関係者の体験談を宣伝に使うときは、スタッフである旨を明記する**（ステマ規制）

### 引用
- 外部記事・口コミの引用は1出典につき1回・短く（目安40字以内）。
  それ以上は完全に自分の言葉で言い換える。元記事の構成をなぞる要約もしない
- **歌詞・詩は引用しない**

## 5. 呼び方の統一（紛れやすいので毎回確認）

| 正しい | 使わない | 理由 |
|---|---|---|
| ご利用中の方 ¥2,000 | 会員価格 | 商品名の「HMC会員」と紛れる |
| シングル／ペア／トリオ | グループ（GOのパーソナルについて） | グループパーソナルと紛れる |
| 4回まとめ／10回まとめ | 4回券／回数券 | 回数券は制度ごと廃止 |
| 1期生 | 第2期 | ジャーニーはチーム制。期の呼び方を統一 |
| フィットネスジャーニー | 7DAYS／30DAYS／ウェルネスジャーニー | 置き換え済みの旧名 |
| HMC会員／セミパ会員 | HACOSメンバーズ | 2026-07-14に廃止した名前 |
| RUNFREE | 朝ラン無料体験 など | 商品名として固定 |

## 6. 個人の心身について書くときの姿勢

- 不健康な食事制限・過度な運動を助長しない
- 医学的に正確な用語を使い、効果を断定しない
- **個人の心身の状態を決めつけない**（「あなたは代謝が落ちています」と言い切らない）
- 体型・年齢を否定的に扱わない。整えることを言い、直すことを言わない
