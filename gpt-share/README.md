# GPT共有パック（ChatGPTにHACOSを引き継ぐための一式）

> 作成: 2026-09-10 ／ 目的: **Claudeで積み上げてきた前提を、ChatGPTでもそのまま使えるようにする**
> 置き場所はこのリポジトリだが、中身は「外部AIに渡す前提で書いた要約」であり、正本ではない。
> **正本は `BUSINESS_RULES.md`（料金・決定事項）と `NEXT_CHAT_HANDOFF.md`＋gitログ（現在地）。**

## このパックが解こうとしている問題

Claudeはこのリポジトリを直接読めるので、料金も現在地も毎回ファイルで確認できる。
ChatGPTはリポジトリを読めないため、**前提を人間が渡さないと、古い価格や存在しない企画を前提に話し始める。**
そこで「渡す内容」を5つのファイルに固定した。

## 渡し方（3ステップ・所要10分）

### ステップ1: ChatGPTで「プロジェクト」を1つ作る
名前は `HACOS / HMC`。会話ごとに前提を貼り直さずに済む。
（プロジェクト機能が使えない場合は、通常のチャットの1通目に `1_GPT_INSTRUCTIONS.md` を貼る）

### ステップ2: プロジェクトの指示欄に貼る
`1_GPT_INSTRUCTIONS.md` の **「■ ここから貼る」〜「■ ここまで」** をコピーして貼る。
文字数制限に引っかかった場合は、同ファイル末尾の**短縮版**を使う。

### ステップ3: 残り4ファイルをアップロードする
プロジェクトのファイル（ナレッジ）に、次の4つをそのまま上げる。

| ファイル | 中身 | 更新頻度 |
|---|---|---|
| `2_BUSINESS_BRIEF.md` | 事業の全体像・商品と価格・体制・システム | 決定が変わったとき |
| `3_CURRENT_STATE.md` | いまどこにいるか・宿題・期限 | **月1回は差し替える** |
| `4_BRAND_VOICE.md` | 世界観・言葉づかい・書いてはいけない表現 | ほぼ変わらない |
| `5_PROMPT_TEMPLATES.md` | よく使う頼み方の型 | 使いながら足す |

## 更新のしかた（これをやらないと1ヶ月で嘘つきになる）

- **料金や商品を変えたとき** … `BUSINESS_RULES.md` を直したあと、`2_BUSINESS_BRIEF.md` の価格表も直す
- **月が変わったとき** … `3_CURRENT_STATE.md` を書き直してアップロードし直す
- Claudeに頼むなら「gpt-share/ を今の状態に更新して」の一言でよい

> ⚠️ ChatGPTにアップロード済みのファイルは、**リポジトリを直しても自動では変わらない。**
> 必ずChatGPT側でもファイルを差し替えること。

## GPTに貼らないもの（安全のため）

| 貼らない | 理由 |
|---|---|
| APIキー・アクセストークン・LINEのチャネルシークレット | 外部サービスに送った時点で漏えい扱いになる |
| 管理画面のURLとログイン情報 | スタッフ用の入口。公開情報ではない |
| **お客様の実名・連絡先** | 本人の同意がない。役割で書けば足りる（例:「ジャーニー1期生のお客様2名」） |
| 未公開の写真・体験談の原本 | 掲載許可の範囲が外部AIには及ばない |

トレーナー名（GO／みどり／片山めぐみ／ちひろ／ふみや／黒田陽子）は**公開LPに実名で載せている**ため、そのまま出してよい。

## ClaudeとGPTの使い分け（迷ったとき）

| 向いている先 | 仕事 |
|---|---|
| **Claude（このリポジトリ）** | LP・予約システムの実装、料金の全ファイル反映、公開前チェック、ファイルの整合を取る仕事 |
| **ChatGPT** | 壁打ち、企画の発散、コピーの別案出し、リサーチ、画像の相談、外出先での相談 |

**ファイルを書き換える仕事はClaude、考えを広げる仕事はGPT。**
GPTで決まったことは、**必ず「これで決まった」とClaudeに伝えて `BUSINESS_RULES.md` に記録する。**
記録しないと、次のセッションからは存在しなかったことになる。

## ファイル一覧

```
gpt-share/
├── README.md                 ← いま読んでいるファイル（使い方）
├── 1_GPT_INSTRUCTIONS.md     ← プロジェクト指示欄に貼る本体
├── 2_BUSINESS_BRIEF.md       ← 事業ブリーフ（変わりにくい前提）
├── 3_CURRENT_STATE.md        ← 現在地（2026-09-10時点・要更新）
├── 4_BRAND_VOICE.md          ← 世界観と禁止表現
└── 5_PROMPT_TEMPLATES.md     ← 依頼テンプレ集
```
